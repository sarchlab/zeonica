 Advances the simulation by `n_clocks` clock steps, running the RISC-V cores and Tensix units. The
 host calls this to let the device make forward progress between or during register accesses. The
 simulator does not advance time on its own; it only runs inside `libttsim_clock`.
 
+`libttsim_get_clock` returns the current value of the simulator's process-global clock counter. The
+value starts at zero after `libttsim_init` and increments once for each simulated clock step advanced
+through `libttsim_clock`. This is a read-only observation point for host-side measurement and does
+not advance simulation time.
